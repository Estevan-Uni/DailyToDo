# 待办可选时间与日历事件名称

2026-11-01 · V27 · 0.1.0 build 16。日期、事项和类型必填，HH:mm选填；月历和周历的事件只显示名称、类型色点及完成/重要标记，不显示时间、逾时钟表或DST提示。已有精确时分不被删除，编辑详情中可查看或修改；卡片/其他列表在有时间时仍显示时分。

## 无时间的边界

- 留空或全空白表示当天待办，不是00:00；主动输入00:00表示零点事项。非空格式/数值非法继续拒绝并保留草稿。
- 单次、每日和每周均可不设时间，同日未设时间排在精确时分之前；没有日内逾时状态。未完成单次仍按日期顺延，周期保留各次日期。
- 单次绝对提醒独立设置，清空计划时分时保留提醒，不自动发起授权；无具体时分不提供按计划平移提醒。重复相对提醒须有具体时分，缺失时明确报错，可改为不提醒后保存。

## 存储兼容

不改变原Core Data/SQLite V1模型，以ScheduledTime.unspecified=-1表示未设时间；0...1439仍表示原精确时分，其他值拒绝。TaskDraft.minute=nil由保存边界归一化；读取草稿恢复nil/空时间。JSON结构不变，新版备份与恢复支持该明确值。旧版本不能理解新未设时间记录，不承诺降级读取；不要启动旧副本写同一库。
