## 工程决策

- 环境：macOS26.6.2（25G83）、Apple silicon arm64、10 CPU、Swift6.2.3、CLT+macOS SDK，无完整 Xcode。macOS14是部署目标，不是已测系统。
- Swift Package 四模块：Domain/Persistence/Interaction/Desktop；程序化 Core Data V1 六实体，不依赖 momc 或外部包。CLT 测试脚本补 Testing 框架路径并禁用缺失的 cross-import overlay，不修改系统安装。
- UI 仅持值模型/草稿；Repository actor 串行写入，读修订到提交之间不挂起；ManagedObject不离开private context队列。
- 自动顺延改同一条记录日期，修订增加；重复、完成、删除排除；不会补发过期的绝对提醒。
- 恢复成功提交前暂停普通写入和调度。数据库加载失败时创建独立候选，导入成功后原子发布活动库 manifest；原库不覆盖，旧 manifest 先备份。
- 文本撤销使用原生文字 undo manager；业务撤销保留最近20条受修订保护的支持操作，恢复/类型迁移/批量前向修改不伪装成通用撤销。
- 卡片手势用局部监听适配纯状态机，隐藏/编辑时移除；手势起点决定分区，纵向锁定后始终透传，惯性期间一次翻页。真实设备体验仍需人工确认。
- Desktop/iCloud会在构建后重新附加FinderInfo。签名与ZIP源在系统临时目录，运行副本在~/Applications；不把工作区同步目录里的.app当作稳定签名源。

## V15 2026-11-01 重复规则确认
