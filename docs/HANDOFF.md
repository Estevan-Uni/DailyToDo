# 本机预览交付与人工验收

2026-11-01 · 0.1.0 build 17 · V28。当前可以开始本机人工验收；完整对外发布尚未通过。

## 打开哪个 App

日常预览使用 `~/Applications/DailyToDo.app`。运行`./scripts/package-app.sh`生成`dist/DailyToDo-macOS-arm64-preview.zip`及SHA256侧车；构建产物不提交Git。当前仅实测macOS26.6.2、Apple silicon；沙盒ad-hoc签名，未公证。

需要样本时用独立验收App，不在正常数据上测试恢复或批量操作。现有“待办验收”“界面验收预览”与日常App身份/数据隔离；无需把这些测试副本当成正式App。

## 建议先做这十项

以下供用户亲自勾选，默认留空，不把开发验证代替你的验收。

- [ ] 打开后只有日程/倒计时两个安排入口；整体颜色、字号与间距符合预期。
- [ ] 切换周/月，确认主体都是日历；上/下周期及今天定位方便。
- [ ] 点击日期空白新增，输入事项、日期和类型，时间选填；点击已有事项在右栏修改，关闭后日历展开。
- [ ] 勾选完成后，App原位划线、卡片隐藏；取消完成可恢复。
- [ ] 建立每日/每周固定事项，完成某一次不影响其他日期。
- [ ] 卡片左侧切七天、上下浏览长列表，右侧上下浏览倒计时，两个分区互不干扰。
- [ ] 在卡片直接增改待办和倒计时；主窗口同步，输入草稿不会无故丢失。
- [ ] 自定义主题及类型颜色，调节卡片背景不透明度；深浅色、复杂壁纸下文字清楚，长标题与四位天数可读。
- [ ] 关闭主窗口后能找回；退出重开后数据、卡片尺寸和位置保留。
- [ ] 在独立验收库导出备份，确认数量后恢复；失败时不覆盖原库。

自动顺延只针对未完成非周期待办，同一记录移到次日，离线多日补到今天；周期和完成记录保留原日期。真实跨午夜/唤醒可留待持续试用验证。
