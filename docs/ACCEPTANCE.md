# 预览版安装与人工验收

版本0.1.0 build 16（V27 DailyToDo），本机 Apple silicon 预览。当前实测 macOS26.6.2；部署目标macOS14，最低系统和Intel未实测。包采用沙盒ad-hoc签名，未做Developer ID公证。此文档同时是人工确认清单，未勾选项不代表已通过。

## 安装与日常使用

1. 运行`./scripts/package-app.sh`后解压 `dist/DailyToDo-macOS-arm64-preview.zip`，将 DailyToDo.app 放到本机 Applications 后打开。不要从iCloud桌面中的旧构建副本判断签名。当前本机安装在 `~/Applications/DailyToDo.app`。
2. 日程默认月历；周/月切换改变日历展示。点击日期空白或顶部+新建，点击已有事项编辑；右栏关闭后恢复完整日历。
3. 待办输入日期、事项和类型，HH:mm选填；可在表单选择每日/每周多选。完成后App原位划线，卡片隐藏；再次点击勾选可取消完成。
4. 桌面卡片左边查看今天起七天，日期条/箭头/键盘可切日，超过高度上下滚动；右边上下浏览倒计时，点击编辑，右键归档/删除。
5. 工具栏调色板和设置可调主题色。类型管理在日程更多菜单，类型颜色独立；重复规则和最近删除也从更多进入，不增加主导航。
6. 设置中导出JSON。恢复会替换全部业务内容，先确认数量并自动备份当前库；恢复成功后旧撤销栈清空。主题、位置和系统授权不随业务备份迁移。
7. 关闭主窗口后卡片和菜单栏继续工作；菜单栏、Dock或设置可找回窗口/卡片。真正退出后卡片消失。通知和登录启动需要用户主动启用，默认关闭。

快捷键：⌘N待办、⇧⌘N倒计时、⌘↩保存、⌘F范围搜索、⌘,设置。文本内⌘Z撤销文字；⌥⌘Z撤销最近支持的业务操作。

## 自动顺延确认

未完成的非周期待办过了本地当天，会把原记录安排日期改为次日；保持ID、时分、事项、类型、备注和重要标记，不复制。多日未运行补移到今天，仍未完成继续逐日顺延。

完成项、最近删除、所有周期实例（包括仅本次改期）不参与。已设置绝对提醒不因顺延重发；App日历和卡片显示新安排日期。旧编辑草稿遇到修订变化会提示冲突，不自动覆盖。

## 开发者隔离验收

```sh
./scripts/test.sh
APP_OUTPUT="$HOME/Applications/TodoDesktop-Validation.app" \
APP_BUNDLE_ID=local.tododesktop.validation APP_DISPLAY_NAME=待办验收 \
./scripts/build-app.sh debug
"$HOME/Applications/TodoDesktop-Validation.app/Contents/MacOS/TodoDesktop" \
--ui-test=新的唯一标识 --ui-demo
```

`--ui-test`限定单独Application Support子目录，名称会清理为安全字符。`--ui-demo`只对空的测试库填合成数据；`--ui-stress`配合它生成当天100项、200倒计时；`--ui-dark`只在明确测试命名空间中使用App深色外观，不修改系统设置。正常启动不启用这些能力。

自动测试和CLI性能基线可重复；触控板、通知、登录和系统版本不能从单元测试推断通过。错误时保留草稿，数据恢复先备份，加载失败不以空库覆盖原文件。
