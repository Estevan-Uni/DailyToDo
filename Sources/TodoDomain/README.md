# TodoDomain

当前领域相关49项测试通过。ReminderTarget.swift统一task-UUID/countdown-UUID身份生成与严格解析，保留既有系统请求ID兼容性；不从标题、日期、URL或通知正文推导目标。2项新增回归覆盖实际ReminderPlan往返、大小写UUID及非法后缀/未知类型拒绝。

`AppClock`提供可发送的当前时刻/时区依赖、同一Gregorian日历、今天/日期投影及显式时区格式化。默认每次读取系统时区，测试可注入固定或受锁保护的可变上下文，不修改系统设置；2项回归覆盖跨年日期/显示与23小时DST日边界。业务民用日期仍固定Gregorian，不因系统首选其他历法改变存储含义。

纯值业务模块，无窗口、数据库或系统通知依赖。

- `LocalDate.swift`：公历年月日、半开日期区间、自然日差、本地时分解析。普通输入限制 1900–9999；10000-01-01 仅用于最后一天的内部查询上界。
- `Models.swift`：任务、类型、系列、规则版本、单次排除、倒计时和版本化快照。
- `Validation.swift`：字段/外键/唯一键/重复规则验证与导出恢复格式。
- `AgendaCalculator.swift`：仅在明确区间内展开规则，合并改期例外，不改变完成、删除或抑制状态。

重复实例以系列 ID + 原发生日标识，ID 由稳定摘要生成。改期不改变原发生键；完成仅作用于一次。查询调用方必须提供按原日期命中的实例，以及按实际日期移入的例外。

JSON `schemaVersion = 1`；`LocalDate` 编为年月日字符串，绝对时刻使用 Foundation Date 的默认参考时刻数值编码，保留精度。编码解码都执行完整校验，双向上限 100 MiB，避免导出不可恢复的超大文件。

当前范围：计算与校验已实现；变更命令、实际数据库事务及 UI 由对应模块实现。没有通过纯计算测试就不能认定持久化与交互已完成。

`DayInterval.week/month` 分别表示自然周与自然月，App 日历查询包含完成项；卡片查询排除完成项。`ReminderPlan` 将待办和倒计时合并为统一时间队列，最多 48 条，保留待补充数量；权限和系统投递不进入纯领域层。

`TaskQuickChange`表达移到本地明天/设置重要的字段级意图；不包含隐式系列范围或新建提醒。日期选择使用同一完整编辑草稿，快改不放宽必填。

`RecurrencePreview.swift`提供有限三次日期和摘要、OccurrencePreview只读投影与复制规则到新草稿。星期通过偏移跳转，含结束日，9999年边界不会越出用户日期；不依赖持久化也不实体化中间年份。

`ReminderRescheduling.swift`仅计算用户明确选择的提醒平移建议；不修改原值、不触发通知。`AgendaClock.swift`提供今天已过时间和下一变化时刻的只读投影，排除完成/删除/抑制；各3项回归，领域相关共43项。

`LocalTimeResolution.swift`统一民用时间到绝对时刻的解析，返回实际时分、UTC偏移和重复时间的两候选。使用有界转换窗口和偏移候选验证，缺口取本日首个合法时刻、重复取最早；整日不存在时返回独立错误。修复当前SDK半小时匹配的次日跳转，LocalDate.instant直接复用；4项解析回归和Persistence同日提醒回归覆盖真实结果。
