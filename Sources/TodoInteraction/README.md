# TodoInteraction

不依赖 SwiftUI/AppKit 的交互状态模块。`ScrollPaging` 接收滚轮差值、阶段、精度和起点位置，输出是否消费与最多一次翻页。

- 起点决定是否属于左侧日期区；同一手势跨分隔线不改变归属。
- 10 pt 后按 1.4 倍主轴比锁定方向；纵向始终交给原生滚动。
- 横向确认阈值为区域宽度 20%，最少 45 pt；惯性结束前最多一页。
- 无阶段精确设备按 150 ms 分组；普通滚轮不触发横向分页。
- 隐藏、编辑、窗口取消或移除监听时 reset，重新启用不接续旧惯性。

AppKit 适配位于 DesktopCard 的 GestureRegion，仅监视本 App、目标窗口。真实触控板体验仍须实机验收；纯状态回归不能替代设备检查。

`MonthCellLayout`集中月历日期格的高度预算，分别预留日期、事项和溢出入口。六行月历可见事项不被“还有N项”挤占；充裕空间展示更多，短格仍通过溢出访问所有记录。4项回归与8项手势回归合计12项交互测试。

`SRGBColor`处理严格#RRGGBB、sRGB线性亮度/对比度、黑白前景选择与向可读色的最小混合。原始颜色不被显示色覆盖；普通浅/深界面和磨砂保护层使用不同参考表面。目标4.5，依据[W3C对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，不代表整套原生App的合规认证。3项颜色回归与原12项交互回归合计15项。

`PanelPlacement`用CoreGraphics值类型进行无窗口副作用的计算：主屏右上初始位置、按显示器标识恢复、按可用区的相对坐标、尺寸钳位与空间不足判断。Codable不保存屏幕绝对坐标。5项位置回归与原15项交互回归合计20项，不替代真实拔屏/拖动。
