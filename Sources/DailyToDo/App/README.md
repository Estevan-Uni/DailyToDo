# App

- `DailyToDoApp.swift`：主场景、设置窗口、菜单栏、快捷命令及关闭/退出草稿保护。
- `AppModel.swift`：一个进程一个 Repository；按当前周/月加载含完成项日程，卡片另取今天起七天未完成项。所有入口的保存、完成、删除、恢复与刷新共用业务命令。

每个编辑入口持有 EditorSession，后台刷新不能覆盖正在输入的草稿；保存失败保留输入，修订冲突可重载或另存。文件恢复先校验、确认并导出原数据备份，再事务替换。启动失败保留原库并报告错误。

主窗口平时只有导航与日历，编辑时展开右栏；窄窗编辑会收起左导航，工具栏保留页面切换。关闭主窗口后进程和菜单栏继续运行，退出前依次处理两个入口的草稿。

- `AppCommands.swift`：文字/业务撤销分流、搜索与设置快捷键；原生文字通知只更新菜单状态，不触发数据库读取。
- `DemoData.swift`：仅明确测试命名空间的可选合成数据，支持100项当天任务/200倒计时压力样例。

`AppModel`在启动、午夜与系统事件维护非周期未完成顺延；刷新保留正在输入的草稿，旧修订不能覆盖。加载失败由DataRecoveryView提供独立新库恢复；成功后才切换Repository和存储路径。正常JSON恢复先备份，暂停调度与普通写入；原库不被提前清空。

启动入口按系统可用性分开：macOS15+使用抑制默认呈现与窗口恢复的场景，macOS14保留同一主场景和AppKit兼容保护。AppLifecycle在主窗口创建前启动数据；菜单栏标签连接主窗口/设置动作。登录/服务来源读取公开Apple Event属性，后台启动只恢复卡片偏好；手动启动主动打开主日历。--ui-login仅隔离测试命名空间可用，日志只报告后台/窗口数/卡片状态，不输出业务内容。真实系统登录和14初始呈现仍需实机检查。

AppModel.quickEdit先处理同记录两个入口的未保存草稿，再读最新修订，避免保存草稿后拿旧标题快照整行改回。菜单栏超出5项提供查看全部动作。启动隔离诊断增加卡片尺寸与是否在屏幕可用区内，不打印显示器ID或业务内容。

入口和首次窗口呈现各接一个GUIProbe检查点；正常启动受双参数门控直接返回。GUI报告只用于隔离Release基线，不把原生窗口布局完成等同屏幕合成或真实输入延迟。

V19：关闭主窗口选择不保存后清除旧编辑会话；编辑倒计时在离开确认保存后重新读取最新记录，避免旧快照写回。原记录删除/抑制时保留草稿和另存路径。刷新只同步正在编辑事项的只读完成时间，不改草稿字段、原始基线或冲突修订。完成状态提示5秒后收起，其他状态会取消旧定时清除；20步业务撤销仍在菜单可用。

倒计时修改/归档/软删除加入同一撤销栈。成功撤销后仅调整与该次恢复快照严格衔接的旧撤销修订，外部修改仍冲突；不会为恢复/批量迁移伪造普通撤销。保存与恢复在数据提交后分别报告通知状态，提醒失败不误报为数据保存失败。

V20：AppModel初始化可注入AppClock和SystemServices，默认装配公开原生客户端。仓库创建与StoreRecovery都沿用同一时钟；编辑器、下一录入草稿、日历跳转、异常时分确认、完成时间格式与目标日提醒共用上下文。displayTimeZone为可观察显示状态，系统时区变化后更新环境而不改写记录。计时/GUI探针仍读取真实时间测量，不拿业务测试时钟充当性能时间。

V21：隔离启动诊断补充实际NSAppearance名；--ui-light/--ui-dark仅在显式--ui-test时设置当前App外观，正常运行无覆盖。Xcode UI宿主复用本目录源码，独立Bundle ID和每用例命名空间，CLI生产路径继续可独立构建。

V22：ReminderNavigation.swift负责通知目标只读定位。先验证存在，再处理主窗口草稿，之后重读当前日期/修订；完成历史、已顺延任务和已归档倒计时都按当前状态打开，缺失/删除/抑制不复活。有效打开清除旧搜索/相关过滤和失效提示；异步读取期间主编辑器、仓库或忙状态变化时不替换新草稿。卡片草稿不被覆盖。

AppLifecycle在applicationWillFinishLaunching安装通知代理，数据与窗口动作就绪后连接打开队列。--ui-open-reminder仅显式--ui-test进程可重放冷启动目标，不发送系统通知；普通启动忽略。AppModel可注入独立存储URL与离开确认选择，Tests/DailyToDoTests直接验证实际模型和临时SQLite。requestRemindersFromEditor只由用户切换提醒/选择重复提前量调用；初始化/打开草稿不请求，已启用不重复请求，拒绝不改输入或数据。

V26：卡片在App隐藏后仍可用；显式showMainAction/showSettingsAction先unhide再激活和打开窗口，普通卡片展示不激活整个App。


V28：AppModel本机保存cardBackgroundOpacity和cardThemeTint，默认18%/开启；背景值读取/写入均钳位0...1，非有限值回退默认。共享可观察状态使卡片与设置即时同步，不触及SQLite数据。
