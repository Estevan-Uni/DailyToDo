# Features

| 文件 | 职责 |
| --- | --- |
| `MainWindow.swift` | 日程/倒计时两入口、按需编辑侧栏、主题颜色、类型与重复规则管理入口；倒计时自适应卡片网格 |
| `CategorySelection.swift` | 主/卡片共用色点名称选择、底部新建/管理及柔和预设 |
| `CardCountdownTile.swift` | 大于四位天数的内部上下布局，保留完整数字 |
| `ManagementViews.swift` | 日程内类型/重复管理、独立可访问控件和关联替代确认 |
| `TaskRow.swift` | 卡片/菜单栏/当天列表共享事项行及日历共用右键动作 |
| `WelcomeView.swift` | 首次一页说明与卡片显示确认，不请求权限 |
| `ScheduleCalendarView.swift` | 月日期网格、自然周七列、前后区间与日期跳转、范围搜索和筛选；月格溢出通过当天列表访问 |
| `DesktopCard.swift` | 等宽七天待办/倒计时 NSPanel、锚定编辑面板、原生磨砂、位置恢复与局部横向手势 |
| `EditorSession.swift` | 独立草稿、原始日期/时间文本、修改检测与共享颜色转换 |
| `RecurrenceDraftPreview.swift` | 表单中的规则摘要、三次日期与首日不匹配说明 |
| `LocalTimeNotice.swift` | 共享缺失/重复时分的实际时间说明 |
| `EditorView.swift` | 待办/倒计时共用表单、类型新建、重复范围、原生日历和显式保存 |
| `TrashView.swift` | 各入口内的最近删除，按页加载待办，恢复与永久删除确认 |
| `DataRecoveryView.swift` | 无法加载数据时提供备份恢复、独立空白新库、原目录和重试 |
| `SettingsView.swift` | 卡片置顶、可选通知/登录、JSON 数据入口 |

月/周改变日历展示形态，不再把事项塞在常驻窄列表里。完成记录不设独立页面，日历原格划线；卡片过滤完成项。日期、事项、时分、类型校验和规则展开复用业务层。

真实界面验证记录在 `docs/IMPLEMENTATION.md`。源码存在或编译成功不等于已通过全部人工验收。

日历取消单格加号，空白区域作为独立新增按钮，事件和完成按钮各自处理点击；顶部统一 +。主题从 AppModel 注入全部入口，系统 ColorPicker 生成不透明 RGB，UserDefaults 保存偏好。

卡片的可观察显隐/编辑状态决定局部滚轮监听生命周期；方向判断复用TodoInteraction。倒计时归档/删除共用AppModel草稿保护，避免从另一入口操作时丢掉编辑输入。

七天滚动视图保留各自原生偏移，切页只改变可见性；非当前页禁用交互且对辅助功能隐藏，避免销毁重建造成位置丢失。数量固定为最多七个，不按无限日期创建视图。

原生侧栏选择与异步离开确认分开管理：取消时回退选择，不覆盖草稿。保存中禁用编辑器；倒计时可快捷填入目标日09:00，过去时刻保留原值并显示错误。

月历事项容量由TodoInteraction.MonthCellLayout按日期格实际高度计算，事项与溢出入口分别预算。统一25 pt事项行与3 pt间距，六行月份仍尽量直接显示事项；溢出popover保留完整列表及新建入口。

`Appearance.swift`封装Color与SRGBColor转换、按窗口colorScheme生成值颜色的AppTheme、ColorInput和带描边的CategoryDot。六预设/原生色井保留，颜色值可键盘直接输入；非法值不写偏好，类型表单禁止提交。日历正文使用语义色、类型仅小标记。

EditorView的修改范围采用菜单控件，避免本机分段控件动态扩展规则表单时的原生约束循环；星期按钮均分宽度，备注保持可滚动固定高度。类型保存期间禁用输入，避免返回后丢弃新输入。

任务行共用编辑/选日期/移到明天/重要/删除菜单。编辑回调携带是否直接展开日期选择，卡片和主窗口仍各自维护草稿。完成时间在详情与日历辅助说明显示；星期类型文字不只用重复图标代替。

卡片新增固定在左下，非今天页有回今天；右标题显示活跃倒计时数。七天完成日期集合仅决定空状态，不把已完成事项放回列表。设置可恢复卡片位置；CardPosition和PanelPlacement处理相对位置，屏幕太小时说明并保留其他入口。

重复管理展示只读三次后续与复制新规则。复制草稿要求明确新开始日期，日期浮层一次消费打开请求；EditorSession用可比较值快照检测修改，规则切换不依赖Set的字符串顺序。前向编辑展示原发生日，提交后本次若被规则隐藏则关闭旧编辑器并说明。

EditorSession保留已存计划/提醒基准，显式开启联动才平移提醒并预览新时刻，默认保持绝对提醒。保存成功重设基准，非法建议不静默回退。时间状态通过AppModel.clockNow和AgendaClock计算，周/卡片展示文字、月格展示图标和完整辅助说明，完成记录不显示逾时提示。

手动日期/时分异常解析由EditorSession判断是否新设或改期，AppModel保存前调用原生确认；普通内容编辑不重复确认。规则预览/管理及日历/卡片共用解释。卡片七个滚动页保留，200ms切换、边界短提示；减少动态效果与提高对比度直接读取系统环境，不新增用户设置项。用户切页公告不触发后台刷新播报。

V19：日历父视图只筛选一次并按日期分组，月格/周列接收有序当日数组，避免各格反复扫描整月。卡片事项移除160ms淡出，减少动态效果时禁用；完成按钮在发起异步任务前忽略同一鼠标连击的后续点击和键盘重复事件，实际物理连击仍需人工验证。

新建表单提供“保存并继续”，下一条仅带日期/时分/类型，内容与规则/提醒均重置；干净默认值成为新基线。错误固定显示在底部，保存失败按字段锚点滚动，标题/时间获得焦点。不可编辑的原记录仍保留另存按钮。MainStatusBar使两个主页面都能显示保存/提醒状态及业务撤销，固定32pt高度。

V20：EditorSession持有装配时钟，下一条/复制/重载均继续使用；CivilDateField读取appClock环境，NativeCalendar显式应用时区和Gregorian日历，SwiftUI提醒控件继承同一环境。完成时间通过AppClock格式化，LocalTimeNotice用显示时区解析。日程视图不再自行读取Date()；日期选择与提醒保存的真实UTC值经原生UI/SQLite核对。

V21：日期新增、日历事件、编辑字段/操作、类型选项、卡片导航/列表/事件增加稳定辅助标识，保留原中文标签与键盘行为。编辑容器和规则预览以contain导出子控件，已原生核对；macOS侧栏行仍按明确标签定位。--ui-minimum-card在隔离启动中将初始卡片设为600×340，applyFrame不保存该初始框；普通启动忽略。浅/深最小卡片100/200项及两侧末项有真实截图，较大字号与实际边缘拖动仍待验。

V23：CategorySelection使用原生List和独立highlightedID。打开时定位当前类型/首项并请求列表焦点，方向键只浏览；回车/空格在此列表范围内提交有效类型，Escape取消，不触发事项保存。原生List可把焦点移动到选中行，因此确认不能依赖根FocusState保持true。类型行保留点按/默认辅助动作，底部新建/管理与原草稿分离；当前系统将内部按钮合并为原生行，验收使用category-options容器与中文行/选中状态，不能再假设内部category-option ID一定导出。

主窗口已原生验证方向键/回车/空格/Escape、取消新建类型保留内容及⌘Return保存；卡片已验方向键/回车/Escape及⌘Return保存，卡片空格和取消新类型仍需补测。普通Tab在本机走标题→日期→时间→备注，普通回车在备注换行；全控件Tab仍遵循系统键盘导航设置，本轮未切换。类型行的实际指针点击和VoiceOver语音仍需实机验证，不以源码或键盘路径代替。
